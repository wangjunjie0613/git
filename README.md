# 面向复杂正常背景的开放集焊缝缺陷定位

本项目研究：在不提供目标未知类别训练标签或测试示例的条件下，定位完整焊缝射线原片中的未知缺陷实例，同时控制复杂正常背景造成的误报。

当前仓库是研究与代码骨架。数据审计、训练和评估均未完成，因此不包含真实性能结论。

## 从哪里开始

1. 阅读 [AGENTS.md](AGENTS.md)：研究目标、数据目录、安全边界、代码入口与论文模板路径。
2. 阅读 [docs/RESEARCH_MAP.md](docs/RESEARCH_MAP.md)：每个研究/论文部分需要的输入、产物和完成条件。
3. 复制 `config/experiment.example.json` 作为本机配置，设置 `WELD_DATA_ROOT`，不要提交真实路径。
4. 按 [scripts/README.md](scripts/README.md) 的顺序实现和运行代码。
5. 论文源文件位于 `paper/main.tex`，文献位于 `paper/references.bib`。在本地 TeX Live + XeLaTeX 下编译；生成的PDF不提交。

## 当前实现状态

- 已实现：清单字段、图像ID唯一性及工件/焊缝跨集合泄漏检查（`scripts/validate_manifest.py`）。
- 待实现：数据整理、分组划分、候选生成、检测基线、正常建模、阈值校准、开放集评估、簇级置信区间。
- 论文内容：结构占位；除公开方法引用外，真实实验结果和结论尚待完成。

清单检查通过只代表表格结构和分组检查通过，不证明数据正确、标注完整或图像为正常。
