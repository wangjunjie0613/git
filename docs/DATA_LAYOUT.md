# 本地数据目录说明

设置`WELD_DATA_ROOT`指向数据根目录。该值只放在本机环境变量或忽略的本地配置里，不写进公开文件。

建议本地目录：

```text
$WELD_DATA_ROOT/
├── raw/           # 原始完整射线图
├── annotations/   # 专家标注、仲裁与版本
├── metadata/      # 匿名身份映射，访问受限
├── manifests/     # 分组后的数据角色清单
└── reports/       # 授权的检测报告与核对记录
```

公共仓库内的`data/*/.gitkeep`只用于保留空目录。示例清单使用虚构ID，不能替代真实清单质量审核。清单校验脚本只检查字段和分组，不读取图像内容，也不判定标注真伪。
