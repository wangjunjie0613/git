# 研究组成与论文写作地图

本文件把课题要求拆成可检查的研究模块。它是实施清单，不含个人周计划、相关工作表或任何实测结论。

| 研究模块 / 论文部分 | 需要准备的内容 | 对应代码/材料 | 完成判据 |
|---|---|---|---|
| 研究目标与假设 | 未知类别定义、研究问题、可证伪假设、最大风险 | `AGENTS.md`、冻结的protocol记录 | 训练、调参、测试的信息边界写清楚 |
| 数据来源与治理 | 授权、原片/试样/焊缝关联、设备来源、标签定义 | `prepare_data.py`、本地metadata和标签字典 | 图像谱系可追溯；缺标不误判成正常 |
| 开放集划分 | 缺陷家族映射、方向性同义类、留出规则、分组划分 | `make_splits.py`、manifest | 工件/焊缝及其所有视图不跨split |
| 候选阶段 | 类别无关候选、候选预算、微小目标覆盖 | `generate_proposals.py` | 报告IoU阈值和目标尺度分层的proposal recall |
| 区域判别方法 | 闭集、纯异常、全局正常、背景条件正常、未知拒识 | `train_detector.py`、`train_normality.py` | 同信息量/预算比较，记录模型和权重来源 |
| 阈值与指标 | 完整阴性验证原片校准；未知实例一对一匹配 | `calibrate_threshold.py`、`evaluate_open_set.py` | 阈值在看测试结果前冻结；误报分母为完整原片 |
| 统计分析 | 按工件/焊缝配对重采样，处理类间异质性 | `bootstrap_ci.py` | 提供簇级CI；不把patch/候选当独立样本 |
| 引言 | 工业问题、开放集定义、研究问题、贡献边界 | `paper/main.tex` | 贡献由完成的真实实验支持 |
| 相关工作 | 焊缝RT检测、工业异常定位、开放集检测、背景建模 | `paper/references.bib`；个人相关工作表另存 | 每条引用可核验；区分任务和信息协议 |
| 数据和实验方法 | 数据流、专家标注、划分、实现、基线与评价 | 数据审计记录、运行配置、代码 | 能从代码版本重现实验流程 |
| 结果 | 候选覆盖、未知召回/误报曲线、已知mAP、消融和CI | `summarize_results.py`；本地运行输出 | 表图与冻结预测一致；不填计划值 |
| 讨论与局限 | 错误案例、域偏移、标签不确定性、样本量限制 | 本地失败案例审阅记录 | 明确哪些结论不被当前数据支持 |
| 复现附录 | 依赖、硬件、随机种子、数据manifest版本、运行命令 | README、配置和私有审计记录 | 不公开敏感数据也能审计研究设计 |

## 推荐的图表证据

1. 方法流程图：完整原片、候选、背景条件、拒识和评估边界。
2. 候选预算-未知目标覆盖曲线：说明候选阶段上限。
3. 固定误报工作点下的未知实例召回曲线：报告实际测试误报/原片。
4. 背景困难类型误报图：比较全局正常、简单拆分、条件模型和困难负样本。
5. 消融与错误案例：漏提名、未知误认已知、复杂正常误报、混合图漏检。
6. 数据与基线主表：焊缝、原片、缺陷实例数；已知性能、未知定位和运行成本。

图表仅在真实实验完成后填入。公共仓库只保留代码和空模板，敏感图像、内部ID、详细结果先存放在受控位置。
