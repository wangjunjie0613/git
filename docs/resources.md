## 用户操作

在服务器终端执行：

```bash
nvidia-smi
```

再进入实际存放图像/标注的文件夹执行：

```bash
pwd
```

数据根目录是数据所在的最外层文件夹，不是GitHub地址，也不是必须新建的目录。图像与标注分开存放时记录两个目录。以上命令不会修改数据。
